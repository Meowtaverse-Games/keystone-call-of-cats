# Stage 8 試作 v1 — 石の待つ谷へ

## 目的

Rhai の待機型 `is_touched()` を、石へ着く前から操作を楽しむ地形で試す。これは Stage 8 だけの試作であり、Keystone 言語の有限 `loop`、`while`、新命令、Stage 1〜7・9〜20を変更しない。

製品の既定スクリプト言語は Rhai とし、石には次のコードを入力して F3 で実行する。

```rhai
loop {
    if is_touched() {
        move("right");
    }
}
```

## 地形と遊び

固定 28×18 の地形は旧main (`8ef143d17982a5a19519664bd9829c858ceca4ff`) の Stage 8 を出発点にする。元の岩の塊と高低差、`O`、右側の出口を残し、次だけを調整した。

- 入口から石を見通せる洞窟の折返し下降へ整えた。
- 谷底手前に石と最後の乗降足場を置き、右側へ渡る石の役割を明確にした。
- 右側の崖を二マス幅にして上側の迂回を塞ぎ、谷を石で渡る意図を明確にした。

段差と `O` の消える障害物を越えて石の上へ乗り、接触中だけ右へ進む石で右側の出口へ渡る。

`O` は製品コードで時間経過後に消える障害物である。水は Stage 8 の物語テキストであり、新しい水の物理は追加しない。岩の塊、高低差、石の前後の経路を平らな横一列には置き換えない。

## 試し方と判定

1. 言語設定を **Rhai** にする。
2. Stage 8 で上記のコードを入力し、F3 を押す。
3. 洞窟を進み石へ乗る。未接触なら石は待ち、接触中だけ右へ動くことを確認する。
4. 石を降りて出口へ到達できるかを試す。落下・詰まり時は F3 で石・プレイヤー・`O` の状態をリセットして再試行する。

構造確認では、静的な石のままゴールに到達できないことを確認した。石はシミュレータ座標 `(17, 3)` から右へ9回移動して `(26, 3)` で止まり、右隣のゴール列 `(27, 3)` では停止する。石の上の移動区間はRON上で空いている。

CLIシミュレータは、石の真上にいるプレイヤーを石と一緒に一マス運ぶ離散モデルを持つ。ただしこの地形で入口から石へ乗り、9回の運搬後にゴールへ至るプレイヤー操作計画は、まだ作成・検証していない。Rhaiプログラム自体もCLIでは実行しない。ジャンプ到達モデルは製品物理の保証ではないため、実機の跳躍距離で石なしの抜け道がないこと、A1Xでの操作感、実際の搭乗、クリア、リセットは人の試遊で未確認である。
