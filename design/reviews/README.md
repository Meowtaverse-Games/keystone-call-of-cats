## モデルと証跡

- `main-stage-N.ron`はmainから無変更抽出した原本。`ascii-layouts.txt`は観測した各地形の代表seedとチャンク列。
- 各試験フォルダの`input.plan`は石・プレイヤーの共通操作。`summary.json`に設定、成否、seed群、最終状態を保存。成功した試験の`seed-0-replay.plan`は出口までの具体的操作とassertを含む。
- 共通手順後の出口は`--walk-to-goal`でseedごとに探索して実際に再生した。同じ完全プレイヤー操作列が全seedに通ると主張しない。
- 操作候補の一部は、独立ツールのmap/simモジュールを一時コピーした補助探索で発見した。最終証跡は変更していない正規CLIで再実行した結果である。補助探索は製品機能や網羅的ソルバーとして追加していない。
- 8・11の`expired-obstacles-only.ron`はすべてのOだけを空白へ置換した感度確認用。時間消滅の到達状態を仮定し、待機・接触・同時実行は検証しない。ゲーム側には時間消滅処理があるが、CLIではOを静的な障害物として扱う。
- ツールは離散グリッドであり、Bevyのジャンプ、落下、石との連続衝突、sleep、接触待ち、Rhai実行を保証しない。CLI seedと製品seedも別物。
