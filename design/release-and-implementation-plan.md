# Keystone: Call of Cats — 20面・販売・実装計画 v2

更新日: 2026-09-04

実装担当向けのファイル単位・依存関係・受入条件は`design/stage-implementation-handoff.md`を参照する。

## 決定事項

- 製品版は固定配置の全20面とする。ランダム、変数、石間通信は1.0の必須要素にしない。
- 章構成は「導入」「制御」「採掘」「道づくり」「複数石」の各4面とする。
- `place`は採用する。構文は`place up/down/left/right`、配置可能数はステージ全体で共有する`place_limit`、失敗時は消費せず、リセット時は配置物と残数を初期化する。
- 初回クリア時間は中央値3〜4時間、プログラミング初心者5〜6時間を目標とする。純粋な面攻略の目標時間合計は192分とし、説明・再試行・物語演出を含めて3〜4時間へ収める。
- 無料デモはStage 1〜6、目標30〜45分。製品版へセーブを引き継げる形にする。
- 本体価格はUS$7.99、日本円980円を基準にし、itch.ioとSteamで通常価格を揃える。
- itch.ioは最低価格US$7.99のpay-what-you-wantとし、公開初週のみ10%オフ。Steamも発売後7日間10%オフとする。
- 公開順は「非公開itch.ioテスト → itch.io 1.0 → Steam 1.0」。Steam Early Accessは使わない。

## 難易度を成立させる合格条件

- Stage 1〜4の外部テスター初見到達率を90%以上にする。
- 各面で、ヒントなしの初見中央値が表の目標時間の0.5〜1.5倍に収まることを目安にする。
- 20分以上進展がないテスターが25%を超えた面は、地形・説明・ヒントのいずれかを修正する。
- 章の導入面（1、5、9、13、17）は新コマンド以外の推理を弱くし、章末面（4、8、12、16、20）だけ複合問題にする。
- 初見テスター15人のうち、操作開始者の50%以上が全20面を完走できるまで難易度を調整する。
- 正解コードだけでなく、想定外の短縮解、詰み、石を使わない抜け道も記録する。

ヒントはメカニクスを追加せず、同じ問題を3段階で補助する。

1. 目的を言い換える（例: 「石を先に行かせず、猫が乗る時間を作ろう」）。
2. 使う命令を示す（例: `sleep`と`move right`）。
3. 最初の1〜2行またはコード骨格を示す。

## 実装計画

### 検証環境の分離

- このサーバではBevy本体をビルドしない。地形、解法、到達性、回帰は`tools/stage_sim`と`./design/verify-all.sh`だけで検証する。
- Bevyへのデータ移植とコード変更はレビュー可能な小単位で行い、本体ビルドと実機操作確認は別の開発PCまたは負荷上限を設定したCIで実施する。
- Bevy確認待ちは「解法未検証」ではなく、物理挙動、入力猶予、演出、UIの製品環境確認待ちを意味する。

### Phase 0: 設計凍結（2026-09-04〜09-11）

- 本書とステージ設計シートV2をチーム内の正本にする。
- `place`仕様、ステージデータの`place_limit`、複数石での共有方法を上記の決定に固定する。
- CLIの20面一括検証を変更時の必須チェックにする。

完了条件: `./design/verify-all.sh`で20/20成功し、シートの未決定欄がない。

### Phase 1: 既存能力の15面を製品化（2026-09-12〜10-09）

- Stage 1〜12、17〜19を`assets/stages/`へ順に移植する。
- 各面で衝突、乗車、ジャンプ、`sleep`、同時実行、採掘上限をBevy実機確認する。
- ステージ選択、クリア保存、リセットを20面前提へ揃える。

完了条件: 15面を通しで開始・リセット・クリアでき、CLIとの差分が解消または記録済み。

### Phase 2: `place`と残り5面（2026-10-10〜11-06）

- パーサー、実行系、能力表示、地形生成、残数UI、リセットを実装する。
- Type4の能力を`move / is_touched / is_empty / place`にする。
- Stage 13〜16、20を移植し、共有`place_limit`と複数石の同時配置を検証する。

完了条件: 配置成功時だけ残数を消費し、占有マスへの配置を拒否し、リセット後に完全復元できる。

### Phase 3: 学習曲線と製品UI（2026-11-07〜12-02）

- 各面に開始説明、命令説明、3段階ヒント、クリア後の短い振り返りを入れる。
- デモ範囲Stage 1〜6、製品版へのセーブ移行、設定保存を確認する。
- 日本語・英語・簡体字の画面欠けとキーボード／コントローラー表示を確認する。

完了条件: 初見テスト5人でStage 1〜6の重大な進行停止がなく、中央値30〜45分。

### Phase 4: 外部テストと難易度調整（2026-12-03〜2027-01-08）

- Steam Coming Soonページと無料デモを2026-12-03までに公開する。
- itch.ioの非公開ページ／キーで15人以上に配布し、面別時間、再試行、ヒント、離脱理由を集める。
- 変更は原則として説明、ヒント、地形、数値に限り、新メカニクスを追加しない。

完了条件: クラッシュなしセッション99%以上、Stage 1〜4初見到達90%以上、全20面完走50%以上。

### Phase 5: 公開（2027-01-14〜02-16）

- itch.io 1.0: 2027-01-14（木）。初週10%オフ。
- itch.ioの障害・難易度修正をSteam候補版へ反映する。
- Steam 1.0: 2027-02-16（火）。初週10%オフ。週末発売は避ける。

リリース日は品質ゲート未達なら動かす。面数を増やして日程を守ることはしない。

## プラットフォーム戦略

### itch.io

- 非公開テスト配布と小刻みな差し替えに使い、最初の外部検証環境とする。
- 公開1.0はSteamと同じ20面・通常価格にする。購入者が上乗せできるpay-what-you-wantを有効にする。
- 常時セールは行わず、公開初週だけ10%オフ。更新履歴と既知の問題をページ上に明記する。
- Windows/Linux版を優先し、Web版はセーブ・入力・性能が同等と確認できた場合だけデモとして出す。

itch.ioは初期費用がなく、売上分配率を設定でき、最低価格を設定したpay-what-you-wantを利用できる。決済の固定費比率を考えると低すぎる価格を避けるべきであり、US$7.99は20面・3〜4時間の小規模完成作として扱いやすい。

参考: [Pricing](https://itch.io/docs/creators/pricing), [Getting started FAQ](https://itch.io/docs/creators/faq), [Payments](https://itch.io/docs/creators/payments), [Quality guidelines](https://itch.io/docs/creators/quality-guidelines)

### Steam

- ストアページは発売の約10週間前、2026-12-03までにComing Soonとして公開し、ウィッシュリストを集める。
- デモはStage 1〜6で固定し、完全版の20面や後半能力を見せすぎない。セーブ引き継ぎを明記する。
- 通常価格US$7.99／980円、発売割引10%を7日間。発売後の値引きはSteamのクールダウン規則に従う。
- プログラミング教育よりも「猫を動かしながら石へ命令を書く、固定解だけではないパズル」を最初の訴求にする。
- ストア素材は、猫の直接操作、コード入力、石が地形を変える結果、複数石の総合問題の順で見せる。

Steam Directは1製品US$100で、Adjusted Gross RevenueがUS$1,000に達すると回収可能。Coming Soonは最低2週間必要だが、ウィッシュリスト獲得のため告知開始時点で公開する。発売割引は10〜15%、7〜14日がSteamの推奨範囲なので、本作は最小側の10%・7日を採る。

参考: [Steam Direct Fee](https://partner.steamgames.com/doc/gettingstarted/appfee), [Coming Soon](https://partner.steamgames.com/doc/store/types), [Pricing](https://partner.steamgames.com/doc/store/pricing), [Discounting](https://partner.steamgames.com/doc/marketing/discounts)

## 価格判断

近いプログラミング／自動化パズルは、現行のSteam通常価格で概ねUS$9.99〜19.99に分布する。本作は20面・初回3〜4時間であるため、その下側にUS$7.99を置き、「短いが完成した作品」として売る。面数を増やして価格を正当化せず、難易度曲線、ヒント、安定性、演出へ工数を使う。

比較例: [Human Resource Machine](https://store.steampowered.com/app/375820/), [while True: learn()](https://store.steampowered.com/app/619150/while_True_learn/), [The Farmer Was Replaced](https://store.steampowered.com/app/2060160/), [Turing Complete](https://store.steampowered.com/app/1444480/)
